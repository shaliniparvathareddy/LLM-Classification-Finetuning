# LLM Classification Fine-Tuning – Kaggle Competition

## About the Project
This project focuses on classifying responses generated by two different language models. It predicts whether Response A wins, Response B wins, or both responses are tied.

The project uses a combination of traditional machine learning techniques and LLM fine-tuning to improve classification performance.

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- PEFT (LoRA)
- Sentence Transformers (MiniLM)
- LightGBM
- Scikit-learn
- NumPy
- Pandas
- SciPy
- Kaggle Notebook

## Methodology
The project follows these main steps:

1. Data loading and preprocessing.
2. Data cleaning and duplicate checking.
3. Text feature extraction using Word and Character TF-IDF.
4. MiniLM embeddings for text representation.
5. Feature engineering and normalization.
6. LightGBM model training and hyperparameter tuning.
7. Logistic Regression classification.
8. LLM fine-tuning using LoRA.
9. Model blending and probability calibration.
10. Final prediction generation and submission.

## Models Used
- LightGBM
- Logistic Regression
- MiniLM
- Qwen / compatible decoder LLM with LoRA fine-tuning

## Evaluation Metrics
The models are evaluated using:
- Log Loss
- Accuracy
- Precision
- Recall
- Macro F1-Score
- Confusion Matrix
- Matthews Correlation Coefficient (MCC)

## How to Run
1. Clone this repository.
2. Open the notebook in Kaggle.
3. Add the competition dataset.
4. Attach the required pretrained LLM model through Kaggle Inputs.
5. Enable GPU acceleration.
6. Run all notebook cells.
7. The final `submission.csv` file will be generated.

## Output
- `submission.csv` – Final competition predictions.
- Evaluation metrics and model comparison results.
- Training and validation results.

## Note
The LLM fine-tuning stage uses LoRA to reduce training cost and memory usage. The notebook also includes a classical machine learning pipeline as a fallback if LLM fine-tuning or inference cannot be completed.

This project was developed as part of a Kaggle LLM classification fine-tuning competition.
